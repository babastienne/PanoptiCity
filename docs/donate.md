# Donate

## Support the awesome project behind PanoptiCity 💖

Let’s talk about something important: supporting the incredible projects and people that make PanoptiCity possible! 🚀

### Give love to the real heroes 🦸‍♀️🦸‍♂️

PanoptiCity is built on the shoulders of giants - amazing open-source projects that pour their heart and soul into creating free, powerful tools. Before you even think about donating to PanoptiCity, you should support the projects that truly make this possible!

### Top projects to support 🌟

Each of these projects is crucial to PAnoptiCity. If you appreciate this website, show some love to these incredible teams:

- OpenStretMap foundation 🗺️: [Donate Here](https://supporting.openstreetmap.org/donate/)
- PostgreSQL 📁: [Donate Here](https://www.postgresql.org/about/donate/)
- OSM2PGSQL 🔁: [Donate Here](https://osm2pgsql.org/sponsors/)
- Osmium 🌍: [Donate Here](https://osmcode.org/sponsors.html)
- Django 💻: [Donate Here](https://www.djangoproject.com/fundraising/)
- DjangoRestFramework 🌐: [Donate Here](https://www.django-rest-framework.org/community/contributing/)

They're not looking for donations, but this project in here also thanks to the incredible work done with the [SunderS](https://sunders.uber.space/) project and [Leaflet](https://leafletjs.com/) library.

## PanoptiCity donations: the very last priority 🏆

Okay, so you REALLY want to support PanoptiCity? First, thank you! But honestly, I’m not doing this for money. PanoptiCity is a passion project I created for myself and other enthusiasts. If you want to support me, consider contributing to the open-source projects above first. 

## Special thanks 🙌

PanoptiCity wouldn’t exist without:

- The amazing open-source community
- My incredible friends who provided feedback
- The [SunderS](https://sunders.uber.space/) project and the original [osmcamera](https://github.com/khris78/osmcamera) project

- The maintainers of all the leaflet plugins
- YOU 🫵 - for using, supporting, and believing in PanoptiCity!

Remember: The best way to support PanoptiCity is by using it, sharing it, and helping others in our community! 🤝
